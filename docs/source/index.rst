Delay Prediction Platform
=========================

Справочник разработчика формируется из Python-модулей и их docstring.
Ссылки «Исходный код» открывают реализацию функций и классов.

Поток данных
------------

Приёмник NDTP сохраняет телеметрию в базу входных данных (БД 1).
ML-воркер читает телеметрию и расписание, рассчитывает признаки и прогнозы,
сохраняет результаты в БД 2. Воркер аналитики рассчитывает состояние сегментов.
Backend читает данные для диспетчерского интерфейса; модель в HTTP-запросах
основного backend не вызывается. Очисткой БД 2 занимается maintenance.
В historical-режиме процесс scripts.replay координирует расчёты по времени потока.

Отдельный ml.service предоставляет HTTP-интерфейс для ручного вызова модели.
Он не запускается стандартным compose.yaml.
